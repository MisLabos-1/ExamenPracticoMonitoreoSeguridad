# Infraestructura

## Plataforma

El laboratorio se ejecuta localmente sobre Windows utilizando
WSL2 y Ubuntu 24.04 LTS.

## Arquitectura

Windows
└── WSL2
    └── Ubuntu 24.04
        └── Docker Engine
            └── Docker Compose

## Objetivo

Proporcionar una infraestructura local para ejecutar la
plataforma DevSecOps sin depender de servicios de nube pública.

## Componentes principales

- WSL2
- Ubuntu 24.04 LTS
- Docker Engine
- Docker Compose
- Git
